# Rebuilding the designs

Everything in `03-identity/motifs/`, `03-identity/campaign/`, `02-photos/graded/` and `04-designs/exports/` is generated by these scripts.

```bash
cd 04-designs/source
pip install -r requirements.txt
playwright install chromium

python make_motifs.py    # brick tile + frieze, palm silhouettes, star fields, grain -> 03-identity/motifs/
python grade_photos.py   # the five design photos -> 02-photos/graded/
python build.py local    # layouts as HTML -> _build/prev_*.html
python export.py         # JPGs, A4 PDF, countdown 7..1 -> 04-designs/exports/ ; seal + title -> 03-identity/campaign/
```

`python build.py dc` writes the same layouts as artboards for the online Design canvas (`_build/canvas/project/*.dc.html`), using the canvas image addresses in `canvas_blob_urls.json`.

## Changing the content

All text is in `build.py`: the header (`header()`), the title and tagline (`title()`), the three facts (`info_items()`), the phone (`cta()`), the prices (`prices()`), and the seal ring (`seal()`). Colours are in the `C` dictionary at the top and match `03-identity/tokens.json`. Each format (`feed`, `a4`, `story`, `endcard`, `countdown`) only sets positions and sizes.

For a new event, copy this folder, change the texts and the hero photo in `grade_photos.py`, and keep the anatomy described in `03-identity/README.md`.
